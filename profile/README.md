## Get started in 3 steps

| | |
|---|---|
| **1. Upload a song** | At [kinetune.com](https://kinetune.com/?utm_source=github&utm_medium=readme&utm_campaign=org) or in the app. Kinetune hears every word. |
| **2. Pick what to make** | A lyric video, a Canvas, a music video, cover art. You see the exact credits first. |
| **3. Say yes** | Nothing is made until you do. Download it and post it. |

## Build with Kinetune

Everything in the app is also an API call, so agents, scripts and automations can make the same videos.

| Repo | What it is |
|---|---|
| 🤖 [**skills**](https://github.com/kinetune/skills) | The Kinetune skill and plugin for Claude Code, Codex, Cursor and other agents, plus the hosted MCP server at `https://kinetune.com/mcp` |
| ⌨️ [**cli**](https://github.com/kinetune/cli) | `npx @kinetune/cli`: every operation from the terminal, JSON when piped |
| ⚙️ [**n8n-nodes-kinetune**](https://github.com/kinetune/n8n-nodes-kinetune) | The Kinetune node for n8n workflows and AI agents |
| 🔌 [**REST API**](https://kinetune.com/developers/rest?utm_source=github&utm_medium=readme&utm_campaign=org) | OpenAPI 3.1, API keys or OAuth, webhooks when a video is done |

Every tool shows the exact credits first and makes nothing until you say yes.
